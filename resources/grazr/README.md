# grazr engine

The Python rotation engine behind Claude Accounts. It is copied into the app as an extra resource at `resources/grazr`, and packaged builds read it from `grazr/engine` under the app's resources directory. The source and upstream history live in https://github.com/senadaruc/herdr-grazr (branch `orca-port`, MIT, licence in `engine/LICENSE`); see `engine/` for the vendored files and `VERSION` for the version they were copied at.
